Advancing in R

Author

Philip Leftwich & Ed Ivimey-Cook

Overview

This course is for anyone with a basic knowledge of R who wants to improve their programming. Each session is hands-on: you work through practical examples that apply what you have learned, with plenty of support for your questions and anything you get stuck on.

Learning outcomes

  1. A grounding in R
  2. Project based workflows
  3. Tidyverse for data wrangling
  4. Writing functions and running iterations
  5. Advanced tidyverse tricks
  6. Reproducibility and code review
  7. ggplot2 for data visuals
  8. Making tables with gt
  9. Making reports with Quarto
  10. Using GitHub
  11. AI-assisted programming

How to use this book

For many of the chapters, we will provide the code you need to use. You can copy and paste from the book using the clipboard in the top-right corner.

We also provide the solutions to many of the activities. No-one is going to check whether you tried to figure it out yourself rather than going straight to the solution, but remember this: if you copy and paste without thinking, you will learn nothing.

Finally, we update the book from time to time, fixing typos and adding detail or activities, so treat it as a living document. Please tell us if you find any mistakes.

Before the course

The course runs live on Zoom, so please have everything below working before the first session. Setup problems are much harder to fix over a video call.

Setup checklist

  1. R 4.3.0 or later (ideally the current release) from CRAN, and RStudio or Positron.
  2. Windows only: install Rtools that matches your R version. You need it to install ThemePark from GitHub.
  3. Git, installed and working (see the GitHub chapter if you are unsure).
  4. The packages: copy the script below into the R console and run it. It installs everything the course uses, then checks your versions. It can take 10–20 minutes.
  5. A GitHub account, and access to an AI assistant. For Day 4 (AI-assisted programming), sort out access in advance. The day uses Claude Code (needs a Claude subscription or Console account), Posit Assistant (Posit AI or your own provider key) and GitHub Copilot (Copilot Free covers inline suggestions and chat; students and teachers can apply for Copilot Student, and the paid plans include the cloud agent). You do not need all three. If you will use Claude Code, install it and run the checks in Setting up Claude Code before the day. GitHub paused new individual sign-ups for some plans in 2026, so don’t leave this to the day. If you can’t get access to any of them, you can still follow along with browser chat on a free account.
  6. Zoom with chat available. You’ll post answers and screenshots in the chat throughout the course.
