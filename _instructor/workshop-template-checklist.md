# Day 4 workshop template: checklist

The participant template repository that learners fork before Day 4. The
Day 4 pages (11a, Blocks 2–8 and the two self-study pages) assume exactly
this layout. Quarto ignores this folder, so nothing here is published.

**Source of truth:** `_instructor/template-files/` holds every file the
template ships that is not data. Copy that folder's contents into the
template; the pages print several of these files directly from there, so the
book and the template cannot drift apart.

**The live day:** Block 1 Framing (`11`), 2 Debugging (`11c`), 3 Context,
disclosure and autonomy (`11d`), 4 Instructions and skills (`11e`), 5 Enforced
controls (`11f`), lunch, 6 Build your own agent (`11k`), 7 Data cleaning
(`11g`), 8 Characterisation tests (`11i`), 9 AI-assisted code review (`11h`,
in `~/ai-review`, outside the template), wrap-up. **Self-study:** inline
completions (`11b`), the Copilot cloud agent (`11l`, in the learner's fork on
GitHub; it adds `.github/` files and a plot test there).

## `renv.lock`

Pin: tidyverse, here, testthat, jsonlite, renv, callr, fs, usethis (brings
gert), waldo, and ellmer (Block 6). ellmer stays in the lockfile under renv's
implicit snapshot because `agent/mini_agent.R` loads it. pointblank only if
you teach Block 7's *Going further*. Check the lockfile, not just this list:
the tests use callr and jsonlite directly.

*Going further* only (do not pin unless you teach it): ggdist, ggbeeswarm,
colorspace, colorBlindness, emmeans, ggpubr, patchwork, ggh4x, ragg,
showtext, sysfonts.

## API keys for Block 6

Every learner needs an Anthropic API key with a little prepaid credit, saved
as `AGENT_ANTHROPIC_KEY` in their user-level `.Renviron` (11a Step 7). Rate
limits apply per Console organisation: if you hand out keys from one
organisation, the whole room shares its limits. If keys fail on the day, run
Block 6's Task 2 on screen while learners decide each approval in the chat.

## Checkpoint branches

Learners who stall switch to a checkpoint from the Git pane's branch menu and
carry on. Build each branch on top of the previous one.

| Branch | Adds |
|---|---|
| `checkpoint-skills` | `docs/ai-log.md` (two lines), `mass_change_g` in `explore_voles.R`, `scripts/explore_mass_change_plot.R` (saves to `outputs/` with `ggsave()`), `scripts/fig_house.R`, two edits to `AGENTS.md`, and `.agents/skills/house-figures/` with its `.claude/` copy. No `CLAUDE.md` |
| `checkpoint-cleaning` | Block 6's `scripts/functions/summaries.R` (a version that passes `test_translation.R`) and its log line; `docs/codebook.csv` (the converged codebook from Block 7, with `<unit>` kept for metabolic rate), `template-files/checkpoints/checkpoint-cleaning/scripts/01_clean.R`, and the three `data/derived/` files it writes |
| `checkpoint-refactor` | Block 8's Step 1 state: `scripts/functions/summary_functions.R` (the refactored function, behaviour unchanged), `scripts/05_analysis.R` calling it, `tests/test_summary_functions.R` (the characterisation test), `tests/fixtures/metabolic_summary.rds` (the original reference), and `Edit(/tests/test_summary_functions.R)` in `.claude/settings.json` (Block 8 tells learners to save it to the shared settings file; `settings.local.json` is git-ignored, so a branch cannot carry it) |

The fallback `01_clean.R` reads `docs/codebook.csv` at run time. Against the
planted data it excludes the two duplicate rows (raw rows 31 and 52), sets
five values to `NA`, and handles every planted error as the answer key
expects.

## Before each run of the course

- [ ] Build the template and the three branches from this checklist.
- [ ] On each branch, restart R, then from the R console:
      `testthat::test_dir(here::here("tests"))`.
      Expect `FAIL 0` everywhere. On `main`, `PASS 8` (deny rules, Manual
      mode, no allow rules, the `AGENTS.md` canary and `git status` rule, the
      git repository, the raw-data checksum) and the rest skip; on `checkpoint-refactor` nothing
      skips.
- [ ] Fork the template on a participant-type account and run Blocks 2–8
      with Claude Code, and Block 6 with a key from a brand-new Console
      account: note the number of requests and the cost.
- [ ] `claude --version` is 2.1.281 or later (`AGENTS.md` read directly and
      listed by `/memory`).
- [ ] In Claude Code, `/permissions` lists all 17 rules, and a new session
      starts in Manual mode (not auto).
- [ ] The agent is refused when it tries to edit `data/raw/voles_raw.csv`,
      and allowed to write `scripts/01_clean.R`.
- [ ] `renv::restore()` succeeds on a clean machine, and `renv::status()`
      then reports no problems.

      `checkpoint-cleaning`'s `docs/codebook.csv` matches the converged
